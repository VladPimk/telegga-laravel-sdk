# Security Policy

## Supported versions

Security fixes are provided for the latest released minor version.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not disclose security vulnerabilities in public issues.

Use [GitHub private vulnerability reporting](https://github.com/VladPimk/telegga-laravel-sdk/security/advisories/new) and include the affected version, reproduction steps, potential impact, and any known mitigation.

The report will be reviewed before any public disclosure or release is prepared.
